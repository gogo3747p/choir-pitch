# 星韻魔法學院｜合唱音準闖關遊戲

給國小高年級合唱團的歌唱練習遊戲。學生選聲部、跟著伴奏唱，小鳥會跟著歌聲的音高飛，唱準就能收集星塵、點亮 1–10 顆星，一關一關闖過試煉之塔。

## 使用方式

- 用 Chrome 或 Edge 開啟網頁（需要麥克風權限，建議戴耳機）。
- 老師到「教授辦公室」新增歌曲：可用 MusicXML、輸入簡譜，或（在 claude.ai 版本）拍照辨識樂譜。
- 老師設定好歌曲後，按「匯出學生版網頁」，把匯出的檔案改名為 `index.html` 上傳到這個儲存庫，學生打開網址就能直接練習。

## 開始畫面與學院

開始畫面按「開始遊戲」後選擇學院：三年級（鳳凰）、四年級（貓頭鷹）、五年級（龍）、六年級（獨角獸）、合唱團，分別對應同名資料夾。

## 收錄歌曲

- 合唱團（需輸入密碼）：《麥仔的故鄉》（詞曲：楊婷婷，編曲：潘威丞；經兩位老師同意公開）、《我親愛的朋友》
- 五年級：《Do re mi》、《普世歡騰》（傳統詩歌旋律 ANTIOCH；第二部與鋼琴和弦為簡化新編）

## 功能

- 合唱譜、齊唱譜皆可；多聲部可開啟其他聲部陪唱
- 學徒之路（有導唱）／巫師之路（只有伴奏）
- 速度調整、節拍器、每小節拍數
- 依和弦自動產生鋼琴伴奏，也可上傳伴奏音檔
- 換氣緩衝、八度容許、過關星數等評分設定
- 資料夾分類、資料夾密碼（學生版會加密）、闖關進度、試煉證書下載
- 老師端可看分數與練習紀錄（CSV 匯出）
